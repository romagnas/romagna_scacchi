BENVENUTI SUL MIO GIOCO DI SCACCHI
questo script è fatto a scopo didattico.

1- Aprire "scacchi.exe"

2- inserisci le mosse che intendi fare con le pedine, per esempio: e2(la posizione di partenza)e4(la posizione di arrivo).

3- per uscire dal gioco scrivere "quit" o "q"

gioca con un amico o con chi vuoi!

!!ATTENZIONE!!

nella situazione della promozione* il nome della pedina desiderata deve essere scritto tutto in minuscolo e senza errori grammaticali.

*promozione = quando un pedone arriva nell'ultima riga opposta, per esempio la riga 8 dalla prospettiva dei bianchi, diventa un'altra pedina a piacere, ad eccezione del re.
